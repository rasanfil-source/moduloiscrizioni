# Segnalazioni di sicurezza e privacy

Non inserire dati personali, credenziali o dettagli operativi nelle issue pubbliche.

Per segnalare una vulnerabilità usare, quando disponibile, una segnalazione privata tramite la sezione **Security** del repository GitHub. Includere soltanto le informazioni tecniche necessarie e sostituire ogni dato reale con valori sintetici.

Se la segnalazione riguarda una possibile esposizione di dati personali o segreti, indicare il tipo di dato e il percorso interessato senza riprodurre il valore esposto.
