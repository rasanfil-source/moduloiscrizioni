# 3.26.204 — Scelta automatica del gruppo dell’app

Nella scheda Gruppi → App sul telefono, il cambio del menu a tendina applica subito il gruppo ricaricando la scheda. La sezione resta aperta. Il pulsante «Scegli gruppo» è rimosso; solo quando JavaScript è disattivato compare un comando alternativo «Applica gruppo».

«Salva icona del gruppo» rimane necessario per caricare o ripristinare l’immagine condivisa. La scelta nel menu non modifica gli altri utenti né i permessi.

Installare `dist/modulo-iscrizioni-3.26.204.zip` in WordPress. Apps Script invariato. Pacchetto preparato localmente; sito non aggiornato automaticamente.
