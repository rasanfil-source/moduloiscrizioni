# Rilascio 3.23.29

Il messaggio mostrato dopo il salvataggio di una bozza contiene soltanto l’esito «Bozza aggiornata correttamente.», senza ripetere lo stato né mostrare azioni duplicate.

Nel passaggio conclusivo resta un solo collegamento all’anteprima, dentro le istruzioni. Il comando «Completa la bozza» è stato eliminato e «Pubblica evento» è collocato a destra; sugli schermi più stretti occupa tutta la larghezza disponibile.
