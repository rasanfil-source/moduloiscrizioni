# Modulo Iscrizioni 3.26.246

Aggiunge al portale una preferenza per attivare le notifiche Web Push sul dispositivo in uso. I gestori ricevono gli avvisi per le nuove iscrizioni degli eventi che possono consultare; ogni notifica mostra il nome dell’evento e il logo del gruppo, senza dati personali. Le notifiche vengono accodate dopo il salvataggio dell’iscrizione e inviate tramite il service worker del portale.
