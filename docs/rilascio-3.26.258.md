# Modulo Iscrizioni 3.26.258

- Dopo l'annullamento di una persona, la prenotazione resta in verifica pagamento se i versamenti non sono attribuibili con certezza; non viene confermata usando soltanto l'importo aggregato.
- Le offerte in lista d'attesa prive di scadenza valida vengono risolte alla scadenza comune, se presente, oppure scadono subito. Non possono più bloccare a lungo il controllo periodico.
- Nell'elenco delle prenotazioni, le persone scadute per mancato pagamento sono indicate esplicitamente.
