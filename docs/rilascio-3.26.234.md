# Modulo Iscrizioni 3.26.234

Il plugin gestisce iscrizioni, pagamenti, servizi e comunicazioni usando WordPress come archivio autorevole. Le guide descrivono il flusso operativo corrente e i commenti tecnici del codice sono in italiano.

Il pacchetto locale include la configurazione prevista per l installazione dellorganizzazione; la distribuzione pubblicabile la esclude.
