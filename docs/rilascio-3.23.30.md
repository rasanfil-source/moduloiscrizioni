# Rilascio 3.23.30

- Nel passaggio conclusivo il percorso di modifica di un evento esistente usa il comando **Salva modifiche**.
- La creazione iniziale conserva il comando **Crea la bozza e vai ad Attiva l’evento**.
- La pubblicazione resta un’azione distinta, disponibile soltanto per una bozza e con la propria etichetta esplicita.

Non vengono attivati timer né inviate email.
