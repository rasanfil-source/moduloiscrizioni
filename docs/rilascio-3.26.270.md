# Modulo Iscrizioni 3.26.270

- Nel wizard, le modalità di calcolo delle quote hanno etichette più esplicite: sola iscrizione con quote esterne, quota base fissa, solo servizi selezionati, oppure ticket più servizi con totale calcolato.
- La spiegazione cambia insieme alla modalità e distingue il calcolo del totale dalla modalità di pagamento.
- Prezzi, ticket e regole di incasso restano invariati.
